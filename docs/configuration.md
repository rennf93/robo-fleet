# Configuration reference

Every setting below is read from `robofleet/config.py`'s `Settings` class (Pydantic Settings, `env_prefix="ROBOFLEET_"`, loaded from the process environment and, for local dev, a `.env` file) unless the row says otherwise. Booleans accept `true`/`false`/`1`/`0`/`yes`/`no` (case-insensitive). This file is generated by reading the source directly — if a variable isn't in `robofleet/config.py` and isn't cited as a direct `os.environ` read below, it does not exist in this codebase.

Two deploy shapes read different subsets:

- **Local / self-hosted (docker-compose.yml, docker-compose.registry.yml)** — `.env.example` is the template.
- **GCP Cloud Run (the hackathon deploy path)** — `.env.gcp.example` is the template, and `infra/orchestrator-service.yaml` / `infra/panel-service.yaml` are the actual source of truth for what a real deploy sets (see [deploy.md](deploy.md)).

## A few settings are NOT in the Settings class

These are genuinely read by the code (`os.environ.get(...)`, not `Settings`), so they still belong in `.env` / the Cloud Run manifests, but they won't show up if you only grep `robofleet/config.py` for a `Field(`.

| Env var | Read at | Purpose |
|---|---|---|
| `ROBOFLEET_AGENT_AUTH_REQUIRED` | `robofleet/api/deps.py` (`_auth_required`) | `true`/`false` forces agent-HMAC enforcement on or off; unset falls back to `environment == "production"`. Also consulted by `robofleet/agents_config.py`, the MCP servers, and `robofleet/api/websocket.py`. |
| `ROBOFLEET_AGENT_AUTH_SECRET` | `robofleet/agents_config.py` (`_AUTH_SECRET_ENV`) | HMAC secret that signs/verifies `X-Agent-Token`. Missing = every token verification fails closed. When `gcp_project_id` is set, the value is instead read once from Secret Manager (`{gcp_secret_manager_prefix}-agent-auth-secret`) and this env var is unused. |
| `ROBOFLEET_AGENT_MODEL_DEFAULT` | `robofleet/llm/providers/cloudrun_jobs.py` | Gemini model id the `CloudRunJobsProvider` injects into every agent Job as `ROBOFLEET_AGENT_MODEL`. Default `gemini-3.5-flash`. Not meant to be set by an operator per-request — it's an orchestrator-side default. |
| `ROBOFLEET_AGENT_MODEL` | `robofleet/agent/adk_entry.py` | The actual model id the ADK agent process reads at boot. Set automatically by the Cloud Run Job env (from `ROBOFLEET_AGENT_MODEL_DEFAULT` above); never set this by hand. |
| `ROBOFLEET_HOST_PROJECT_DIR` | `robofleet/llm/providers/cloudrun_jobs.py` (`_api_url_for_agents`) | Local-dev/self-hosted signal only; irrelevant on Cloud Run (`settings.api_url` wins there). |
| `ROBOFLEET_PANEL_AGENT_TOKEN` | nginx config / `robofleet/api/app.py` | The CEO-signed HMAC token nginx injects as `X-Agent-Token` on every `/api/` request in the docker-compose deploy. **Must be unset when `ROBOFLEET_CLOUD_AUTH_ENABLED=true`** — config validation refuses to start otherwise (it's an alternate credential that would bypass the login cookie). Not used on the GCP path at all (no nginx in front of Cloud Run). |
