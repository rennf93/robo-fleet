# RoboFleet Self Documentation

Meta-documentation about the RoboFleet system itself.

## Structure

- `/architecture/` - System architecture docs
- `/incidents/` - Incident reports and post-mortems
- `/reports/` - System reports and analytics

## Access

- **READ**: Main PM, Cell PMs, Product Owner, Auditor
- **WRITE**: Main PM, Auditor

## Purpose

This directory contains documentation about RoboFleet's own operations:
- How the system works
- Issues encountered
- Performance reports
- Architectural decisions
